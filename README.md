# 🏪 Emart24 Clone Coding

> **이마트24 공식 웹사이트 클론 코딩 프로젝트**  
> HTML, CSS, JavaScript를 기반으로 웹사이트 주요 기능을 프론트엔드 중심으로 구현했습니다.

---

## 💡 프로젝트 개요

> Emart24 공식 사이트 구조를 분석하고 HTML, CSS, JS를 활용해 정적인 페이지부터 동적인 인터랙션까지 재현한 팀 프로젝트입니다.  
> 각자 페이지를 담당하여 구현하고, GitHub를 통해 통합 작업을 진행했습니다.

---

## 🖥️ 기술 스택

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **애니메이션**: keyframes, transform, transition
- **유효성 검사 및 UI 제어**: JavaScript 이벤트 리스너, DOM 조작
- **협업 관리**: Git, GitHub

## 💼 담당 파트 (박예린)

### 🛒 상품 페이지
- 행사상품, 차별화상품, Fresh Food UI 구현
- `ul`, `li`, `div`를 활용한 정보 레이아웃 구성
- `onclick` 이벤트를 통한 상품 이미지 전환 및 페이지 로직 처리

### 📬 고객센터 – 온라인 문의
- 이메일 도메인 선택 및 커스텀 입력 처리
- 전체 동의 체크박스 → 개별 항목 자동 반영 및 반대 연동
- 입력값 누락 시 경고창 출력 등 유효성 검사 구현 (JavaScript)

### 📱 APP 서비스
- 페이지 이동에 따라 이미지가 전환되는 애니메이션 구현
- `transform: translate()`로 좌표 이동 및 화면 고정 처리
- 반응형 이미지/움직이는 이미지 별도 분리 구현

## 🔍 주요 기능

| 기능 영역 | 설명 |
|----------|------|
| 반응형 웹 | `vw`, `vh`, `min()`, `calc()` 등 CSS 함수 활용 |
| 상품 페이지 | `onclick`으로 상품 탭 전환, 이미지 반복 출력 |
| APP 서비스 | 페이지별 이미지 전환 애니메이션 구현 |
| 온라인 문의 | 이메일 커스텀 입력 처리, 전체/개별 체크 연동 |
| 유효성 검사 | 필수 항목 누락 시 사용자 경고 출력 |
