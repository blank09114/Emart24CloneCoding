# Emart24 클론 코딩

---
## 프로젝트 개요

이마트24 공식 웹사이트를 분석해 주요 페이지를 구현한 클론 프로젝트입니다.  

- 개발 형태: 웹 인터랙티브 페이지
- 개발 인원: 4인
- 개발 기간: 1주

---
## 기술 스택

| 구분 | 기술 |
|------|------|
| Frontend | HTML, CSS, JavaScript |
| Dev Tools | VS Code |

---
## 구조 설계

### UI 설계

프로젝트 초기 단계에서 화면 정의서를 작성해 페이지 흐름과 UI 구성을 설계했습니다. 이를 기반으로 팀 내 구현 기준을 통일하고, 개발 과정에서 발생할 수 있는 구조 충돌을 줄였습니다.

### 인터랙션 구조

페이지 전환, 스크롤 기반 이동, 입력 검증 등 주요 기능을 JavaScript로 직접 구현했습니다. 별도의 상태 관리 도구 없이 DOM 제어를 중심으로 인터랙션을 구성했습니다.

---
## 주요 기능(담당한 페이지만)

- 상품 페이지: 페이지 상태 기반 상품 리스트 전환
- APP 서비스 페이지: 스크롤 기반 풀스크린 UI 및 애니메이션
- 온라인 문의 페이지: 입력 검증 및 사용자 피드백 처리
- 공통 UI: Header/Footer, 반응형 레이아웃

---
## 구현

### 상품 페이지

onclick 이벤트를 활용해 현재 페이지 상태를 관리하고, 선택된 상품 목록만 노출되도록 DOM을 제어했습니다. 반복 구조를 적용해 UI 일관성을 유지하면서 코드 중복을 최소화했습니다.

### APP 서비스 페이지

wheel 이벤트를 제어해 한 번의 스크롤마다 하나의 섹션만 이동하도록 구현했습니다. transform과 transition을 활용해 이미지 이동 및 애니메이션 효과를 적용했습니다.

### 온라인 문의 페이지

이메일 입력, 체크박스 상태, 필수 입력값 등을 기준으로 단계별 유효성 검사를 구현했습니다. 입력 상태에 따라 UI가 즉시 반응하도록 구성해 사용자 입력 흐름을 제어했습니다.

## 개선점

- 공통 레이아웃을 페이지마다 반복 작성 → 유지보수 비효율
- CSS/JS 미분리 → 가독성 및 구조 문제
- 데이터 하드코딩 → 확장성 부족
- 상태 관리 구조 부재 → 기능 확장 한계
