# 🏪 Emart24 Clone Coding

**Emart24 공식 웹사이트**를 프론트엔드 중심으로 클론 코딩한 프로젝트입니다.

---

## 📌 프로젝트 개요

- **개발 형태**: 웹 인터랙티브 페이지
- **개발 인원**: 4인(오윤석, 박예린, 박시우, 박수경)
- **핵심 목표**: 최대한 실제와 유사하게 구현

---

## 🖥️ 기술 스택

| 분야 | 사용 기술 |
|----|----|
| Front-end | HTML, CSS, JavaScript |

---

## 🔍 주요 기능

| 기능 구분 | 설명 |
|----|----|
| 메인 페이지 | 슬라이드 배너·물품 목록 출력 |
| 이마트24 소개 | 페이지 스타일링 |
| 상품 페이지 | ul/li로 상품 목록 반복 출력 |
| 서비스 | 이미지 전환 애니메이션 구현 |
| 고객 센터 | FAQ 질문/답변 목록 출력, 온라인 문의 시스템 구현 |

---

## 💼 담당 파트

### 🛒 상품 페이지
- 행사상품, 차별화상품, Fresh Food UI 구현
- `ul`, `li`, `div`를 활용한 정보 레이아웃 구성
- `onclick` 이벤트를 통한 상품 이미지 전환 및 페이지 로직 처리

### 📬 고객센터 – 온라인 문의
- 이메일 도메인 선택 및 커스텀 입력 처리
- 전체 동의 체크박스 → 개별 항목 자동 반영 및 반대 연동
- 입력값 누락 시 경고창 출력 등 유효성 검사 구현

### 📱 APP 서비스
- 페이지 이동에 따라 이미지가 전환되는 애니메이션 구현
- `transform: translate()`로 좌표 이동 및 화면 고정 처리
- 반응형 이미지/움직이는 이미지 별도 분리 구현
